# starter-theme

A **neutral, brandless base theme** for the Stateless CMS. The "Nieuwe site" wizard clones this
into a new theme repo; you then restyle it in the Theme Builder.

- `theme.css` — neutral design tokens (`:root`) + full layout/components
- `theme.js` — shared chrome (header/footer/WhatsApp + behaviour) with generic `DEFAULTS`
- `assets/` — generic placeholder logos
